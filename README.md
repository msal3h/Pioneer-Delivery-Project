# Pioneer Delivery — Algorithm Portfolio

CS 413: Analysis of Algorithms  
Language: Python 3

This project contains algorithm implementations for a fictional delivery company, completed as part of my Analysis of Algorithms course.

## Part I — Greedy Algorithms
- Maximum deliveries for one driver
- Minimum drivers needed
- Minimum rejected deliveries
- Counterexample where a greedy strategy fails

## Part II — Divide and Conquer
- Closest pair of delivery locations
- Counting dispatch-order inversions
- Finding the kth smallest delivery time using median-of-medians

Each folder contains its own README with instructions for running the programs and tests.
